## 🚀 About Me

I like building things people actually enjoy using, whether it's a dashboard that makes medical data easy to understand or a small game that has to grab attention in a few seconds.

I'm a software engineer first. I start from the problem, pick the right tool and learn new languages and technologies quickly, because the engineering methods carry over to any stack.
